# 60s & 70s Classics

Beatles, Motown, flower power, glam rock and disco: the timeless classics from 1960–1979 that every generation knows, from grandparents to grandkids.

61 songs, 1961–1979.

## Sources

Hand-picked from:

- Rolling Stone 500 Greatest Songs of All Time (2021 edition)
- Billboard Year-End Hot 100 1960–1979
- Official Charts Company (UK) number ones 1960–1979

The year on each card is the original release year of the single (or of the album for album tracks).

The song data from the game is copyrighted by the respective rights holders of each song.
This repository contains only the reference data, not the actual song audio.
