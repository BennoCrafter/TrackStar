# 80s Hits

Synth-pop, hair metal, MTV icons and Neue Deutsche Welle: the biggest songs of 1980–1989.

59 songs, 1980–1989.

## Sources

Hand-picked from:

- Billboard Year-End Hot 100 1980–1989
- Official Charts Company (UK) best-selling singles of each year 1980–1989
- Offizielle Deutsche Charts Jahrescharts 1980–1989

The year on each card is the original release year of the single (or of the album for album tracks).

The song data from the game is copyrighted by the respective rights holders of each song.
This repository contains only the reference data, not the actual song audio.
