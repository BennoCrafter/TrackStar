# 2000s Throwbacks

The pop, R&B, rock and club hits of 2000–2009: the soundtrack of millennials' school discos, MTV and first MP3 players.

72 songs, 2000–2009.

## Sources

Hand-picked from:

- Billboard Year-End Hot 100 2000–2009
- Official Charts Company (UK) best-selling singles of each year 2000–2009
- Offizielle Deutsche Charts Jahrescharts 2000–2009

The year on each card is the original release year of the single (or of the album for album tracks).

The song data from the game is copyrighted by the respective rights holders of each song.
This repository contains only the reference data, not the actual song audio.
