# Deutsche Hits

Schlager, Neue Deutsche Welle, Deutschrock, Deutschpop and Deutschrap: German-language hits from the 60s to today. A family set where everyone knows at least a few.

51 songs, 1965–2023.

## Sources

Hand-picked from:

- Offizielle Deutsche Charts (offiziellecharts.de) Jahrescharts
- Bundesverband Musikindustrie (BVMI) Gold/Platin awards
- Ö3 Austria Top 40 for Austrian artists

The year on each card is the original release year of the single (or of the album for album tracks).

The song data from the game is copyrighted by the respective rights holders of each song.
This repository contains only the reference data, not the actual song audio.
