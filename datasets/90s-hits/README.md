# 90s Hits

Grunge, Britpop, boy bands, girl power and Eurodance: the biggest songs of 1990–1999.

57 songs, 1990–1999.

## Sources

Hand-picked from:

- Billboard Year-End Hot 100 1990–1999
- Official Charts Company (UK) best-selling singles of each year 1990–1999
- Offizielle Deutsche Charts Jahrescharts 1990–1999

The year on each card is the original release year of the single (or of the album for album tracks).

The song data from the game is copyrighted by the respective rights holders of each song.
This repository contains only the reference data, not the actual song audio.
