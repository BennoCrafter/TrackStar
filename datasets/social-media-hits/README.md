# Social Media Hits

Songs that blew up on TikTok, Instagram Reels and YouTube Shorts: viral dances, sounds and trends from 2019 until today, plus the oldies TikTok brought back. Made for Gen Z (and anyone who scrolls too much).

96 songs, 1977–2025.

## Sources

Hand-picked from:

- TikTok Year on TikTok / Year in Music reports 2019–2025 (newsroom.tiktok.com)
- Billboard TikTok Billboard Top 50 (billboard.com/charts/tiktok-billboard-top-50)
- Spotify Wrapped global top songs 2019–2025
- Billboard Year-End Hot 100 2019–2025

The year on each card is the original release year of the single (or of the album for album tracks).

The song data from the game is copyrighted by the respective rights holders of each song.
This repository contains only the reference data, not the actual song audio.
